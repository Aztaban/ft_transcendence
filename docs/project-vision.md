# Project Vision

Last updated: TBD

## Working title

42 Prague Tutor & Counsellor Hub

## Short description

A web platform for 42 Prague students, tutors, counsellors, head tutors, admins, and student council members.

The platform should make tutor/counsellor information easier to find, help students request evaluations when they are ready, provide project resources for tutors, and give Student Council a public communication space.

## Problem

Current communication around tutors, counsellors, evaluations, resources, and announcements can be spread across multiple places.

Students may not always know:

- which tutors are currently available
- where tutors are sitting
- who is responsible for which project
- how to ask for help or evaluation
- where to find official or recommended resources
- where to send anonymous suggestions

Tutors/head tutors may need better tools for:

- tracking evaluation requests
- assigning/claiming evaluation slots
- managing project resources
- seeing demand for evaluations
- communicating availability

Student Council may need:

- public member list
- announcement board
- suggestion box
- optional non-anonymous suggestions from logged-in students

## Target users

| User type | Needs |
|---|---|
| Public visitor | View tutors/counsellors/student council info and submit anonymous suggestions. |
| Student | Log in with 42, view people/resources, ask for evaluation, optionally identify suggestions. |
| Tutor | Manage profile/status, claim evaluation slots, access project resources. |
| Head tutor | Manage tutors, resources, evaluation flow, roles, and alerts. |
| Counsellor | Manage profile/info and possibly announcements/resources. |
| Student Council member | Manage council profile and announcements. |
| Admin | Manage users, roles, content, permissions, system settings. |

## Core value

The app should be useful even after the project evaluation. It should not be only a technical demo.

## MVP success definition

The MVP is successful when:

- users can log in
- roles and permissions work
- public pages are usable
- tutors/counsellors/student council can be displayed
- students can create evaluation availability slots
- tutors can claim slots
- admins/head tutors can manage basic content
- important actions are visible through notifications/alerts
- the project can run with one command using containers

## Non-goals for the first version

These are not part of the first MVP unless the team confirms them later:

- creating real evaluations directly inside 42 Intra
- full replacement of Intra
- full Slack bot automation
- complex project management system
- AI/RAG assistant
- mobile native app
